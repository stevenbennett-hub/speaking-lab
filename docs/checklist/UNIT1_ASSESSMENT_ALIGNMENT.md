## Journal sets

- Every 10 Daily Learning Journals make one 100-point set (the approved journal rule).
- The weekly checkpoint lists a set in the week each class group writes its 10th, 20th… journal.
- Collection dates are announced by Mr. Bennett; Speaking Lab does not set them.
- With 90-minute blocks, the first set completes in course week 4 or 5, depending on the group and semester.
