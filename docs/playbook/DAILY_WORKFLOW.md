# Teaching from the Playbook: the daily workflow

**Getting to the Lesson Manager:** Preferences → **Teacher tools** → enter the teacher view code. After that, **Teacher tools** sits in the header next to Preferences on that browser. The code is a classroom convenience, not a password or secure sign-in.

**Before the unit (once, about 20 minutes)**
1. Lesson Manager → **Playbook**. Choose your semester and class group.
2. **Planning settings:** enter your class size. The capacity line tells you whether every student fits in the scheduled speech blocks.
3. Read **Needs your confirmation** and decide each item. Nothing changes until you do.
4. Preview the videos you will use. Open **Video viewing guides → Edit or enter verified times**, enter the segment, and tick "I previewed…".

**Each class day (2 minutes)**
1. Calendar → the date → **Quick Teach plan** (or Playbook → the date).
2. Skim it, then **Print one page** if you like paper. Open the links (viewing guide, lab, reading, studio) from the timed sequence.
3. Need more? **Full instructional plan**: talking points, misconceptions, differentiation.

**If you will be out**
- **Substitute plan (one page)** from Quick Teach. It includes the site address, classroom expectations, accommodations, the AI permission and a timed plan for all 90 minutes. Extension work uses only labs, readings and rehearsal the class is ready for.
- The **Full substitute plan** is still available.

**After class (optional, 1 minute)**
- Type a note under **My notes** for that planned day. It is saved in this browser and printed on future plans.
- Change a timing or a step with **Edit**. It is saved as a draft.

**When you want edits on the site**
- Publish → download `unit-1.json` → upload it to `dev` in `site/data/playbook/`. The tests check it.
- Back up your drafts before you change computers.
